# GH-28 — Adversarial critic findings

1. **Critical — two n8n instances with conflicting localhost identities.** Mac Chrome is authenticated to its **own** n8n (`/home/workflows` displays Lina only, `/home/credentials` asks to create the first credential). The Cloud Sandbox `n8n-lina` has Lina plus the previously imported LCH, 0 credentials, and a keeper. Claiming that the Mac authenticated session implies the sandbox n8n credentials are configured is false. Separate identity and callback runbook created; only one can be activated.
2. **Critical — Microsoft OAuth was never configured.** The actual Mac n8n editor requires Microsoft Outlook OAuth2 Client ID + Secret, with a self-hosted callback pointing to the **Mac** localhost. User authentication to the n8n owner account is not an OAuth2 grant. No Graph API call or Outlook send has been made. Production release blocked.
3. **High — Firestore CAS failure could stop an entire send batch.** Previous node chain stopped by default on a Firestore conditional-write conflict, leaving any earlier claims leased and retrying after timeout. The claim node now continues errors, and a dedicated Code verifier requires the persisted matching lease before sending.
4. **High — provider failures needed explicit acceptance verification.** Native Outlook v2 operation source returns `{success:true}` on successful `/sendMail`. The Outlook node now continues errors and a new Code verifier requires that exact success boolean before allowing any `notification.state=accepted` write. Prevents `continueOnFail` errors from falsely marking customer contacts as notified.
5. **High — exhausted retries previously skipped forever.** `Prepare eligible leads` skipped attempt counts >=7 without persisting `needs_review`, despite documentation implying review state. GH-28 adds a **separate CAS-protected dead-letter branch** for consented, source=website records created after activation with >=7 attempts and expired sending leases. It never invokes Outlook and sets `notification.state=needs_review` with `retry_limit` machine code.
6. **Medium — visitor data and test lead retention.** n8n workflow remains inactive and stores no full execution data, no automated consent changes and no client-side secrets. HTML is escaped and To recipient list is immutable. Real QA records must be excluded from sales processing.
7. **High — accepted does not mean delivered.** Graph/Outlook API success is not confirmation of actual four inbox receipts. Independent Outlook or Exchange message trace still required. Crash after provider acceptance but before Firestore ACK can cause duplicates; stable `x-lch-lead-id` remains the reconciliation key.
8. **Medium — reliability scope.** GH-27 keeper protects only Cloud Sandbox n8n, not Mac host n8n. Full host/container recreation has not been verified. Cloudflare Worker alternative GH-25 has not been deployed. A single runtime selection and validated uptime are prerequisites.

**Source/code quality: PASS following 14/14 n8n tests and full regression. Delivery: NOT PASS.** This critic did not run IBM Granite inference; findings are based on verified source, native n8n code and browser/admin contract evidence.
